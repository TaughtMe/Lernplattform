# Lernraum

Gemeinsam lernen, im Unterricht und zu Hause.

Dieses Repository enthält den gemeinsamen Lernraum: die schülerorientierte Startseite, Klassenbereiche und die integrierten Anwendungen. LernBoxV2 und Laufdiktat werden mit ihrer bestehenden Fachlogik und ihren vollständigen Funktionsabläufen übernommen; der Lernraum ergänzt Navigation, Klassenfreigaben, Identität und Ergebnisübergabe.

## Lokal starten

```bash
npm install
npm run dev
```

## Prüfen

```bash
npm test
npm run lint
```

Die Architekturentscheidungen stehen in [docs/architecture.md](docs/architecture.md), der verbindliche Coding- und Bibliotheksstandard in [docs/engineering-quality.md](docs/engineering-quality.md) und die mobile Teststrategie in [docs/device-support.md](docs/device-support.md). Die vollständige fachliche Konzeption liegt derzeit unter `obsidian-export/Lernplattform`.
