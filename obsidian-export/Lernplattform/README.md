# Lernplattform

Diese Obsidian-Struktur dokumentiert das Gesamtkonzept der Lernplattform.

Startpunkt: [[00 - Übersicht]]

Jeder nummerierte Ordner beschreibt einen Funktionsbereich und enthält eine Datei `Anwendung.md`. Die Nummerierung bildet eine sinnvolle fachliche Reihenfolge, ist aber noch keine technische Ordnerstruktur des späteren Quellcodes.
