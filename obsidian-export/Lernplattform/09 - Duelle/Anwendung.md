# Duelle

## Zweck

Duelle machen den persönlichen oder gemeinsamen Wortschatz spielerisch abrufbar.

## Ablauf

1. Schüler öffnet **Duell**.
2. Er wählt einen oder mehrere Teilnehmer.
3. Inhalt und Duellart werden festgelegt.
4. Alle bearbeiten dieselben Aufgaben in unterschiedlicher Reihenfolge.
5. Richtigkeit zählt stärker als Zeit.
6. Neue Vokabeln können anschließend freiwillig übernommen werden.

## Duellarten

- gemeinsamer Lehrerstapel
- Herausforderer-Stapel
- Wechselduell: Hälfte von Spieler A, Hälfte von Spieler B
- Lehrerduell
- bestimmter Tag oder bestimmte Box
- schwierige oder zufällige Wörter

## Lernwirkung

- pro Duell höchstens ein Aufstieg je Vokabel
- Fehler beeinflussen die jeweilige Richtung
- Zeit beeinflusst Punkte, nicht den Boxstand
- freie Eingabe zählt stärker als Multiple Choice
- häufige Wiederholungen dürfen kein künstliches Hochspielen ermöglichen
