# Inhaltswissen je Lernbereich

Beim Umbau auf das Design „Lernraum UI“ (Entscheidung 47) gilt: Was der
bestehende Code fachlich kann, wird im Design-Layout übernommen. Zeigt das
Design etwas, das es fachlich noch nicht gibt, wird es entweder mit
gekennzeichneten Beispielinhalten gefüllt oder bewusst weggelassen. Dieses
Verzeichnis hält fest, **was es fachlich gibt, wo es liegt und was für die
spätere Anbindung fehlt**, damit das Wissen nicht im Umbau verloren geht.
